# 🩸 AI Blood Report Analyzer

An AI-powered health analysis application that extracts information from blood test reports and generates personalized Indian dietary recommendations using Large Language Models (LLMs).

## 🚀 Live Demo

https://blood-report-ai-analyzer-3nxet8ghagkgy3nluenrtk.streamlit.app


## 📌 Overview

AI Blood Report Analyzer allows users to upload blood test reports and receive:

* Extraction of blood parameters
* Identification of abnormal values
* Simplified explanations of abnormalities
* Personalized Indian diet recommendations

The application uses LangChain workflows and Gemini/Groq models to process medical reports and generate actionable insights.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Rachel-Mathew25/blood-report-ai-analyzer.git
cd blood-report-ai-analyzer
```

### Create Environment Variables

Create a `.env` file:

```env
GOOGLE_API_KEY=your_google_api_key
GROQ_API_KEY=your_groq_api_key
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
streamlit run app.py
```
